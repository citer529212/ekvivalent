# Эквивалент — английский и перевод

Учебная программа для диагностики уровня английского, грамматики, лексики, чтения и перевода RU ⇄ EN.

## Возможности

- Диагностика A1–C2: базовый и расширенный тесты.
- 148 тем и 11 910 тренировочных заданий.
- 2 000 заданий в дополнительном диагностическом банке.
- 40 уроков, 322 параллельных текста и 123 справочных правила.
- Лексика A0–C1, карточки с интервальным повторением, словарный поиск.
- 10 занятий по аудированию A1–C1: записи, вопросы на смысл и детали, пропущенные слова, разбор и повторение вслух.
- Плеер с выбором скорости, повтором A–B и сохранением позиции; раздельная статистика понимания без текста и с поддержкой.
- Короткие тренировки с системной озвучкой, черновики перевода, светлая и тёмная темы.

Результат диагностики ориентировочный; программа не заменяет стандартизированный экзамен. Свободные переводы сопоставляются с образцами и могут оцениваться самим учащимся.

## Использование

GitHub Pages публикует содержимое ветки `main` из корня репозитория. Сборка и сервер приложений не требуются.

Для локального запуска:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000/`. JSON-материалы загружаются через HTTP, поэтому открывать `index.html` через `file://` не рекомендуется.

## Прогресс

Прогресс сохраняется в браузере отдельно для каждого адреса сайта. Для переноса между прежней версией и GitHub Pages скачайте JSON в разделе «Прогресс», затем восстановите его на новом сайте. Пользовательские результаты и черновики в репозиторий не входят.

## Источники

Учебные материалы адаптированы из предоставленного файла «30.10.html» («Эквивалент»). Источники словарей и условия их лицензирования указаны в [ATTRIBUTION.md](ATTRIBUTION.md) и внутри программы.

## Управление и мотивация

- В заданиях Enter проверяет ответ; после разбора следующий Enter открывает следующий вопрос. В диагностике Enter сразу сохраняет ответ и переходит дальше.
- A–D или 1–4 выбирают вариант; ввод текста не перехватывается. Удержание Enter не пропускает вопросы.
- «Сегодня» показывает следующий шаг, «Мой учебный план» — последовательность, «Быстрая практика» — самостоятельный выбор навыка.
- XP: 10 за новое задание в день и ещё 5 за верный ответ. По достижении дневной цели открывается игра на переводные пары. 30 бонусных XP за игру — один раз в день.
- «Занятие с репетитором» — личная учебная цель на 1 000 XP с подготовкой вопросов, а не обещание бесплатного занятия или денежный приз.
- Звуки интерфейса включаются отдельно в разделе «XP и награды»; по умолчанию выключены.

План следующего этапа: [аудио, видео и развитие аудирования](docs/audio-video-roadmap.md).

## Проверка

`node check.cjs` проверяет прежние разделы и управление. `node check-listening.cjs` проверяет данные десяти занятий, прохождение всех этапов, поддержку текстом, Enter, сохранение, импорт, XP и модель событий плеера. Это проверки логики в VM, а не визуальный тест браузера. MP3 перед публикацией проверены декодированием через ffmpeg.

## Персональный план и тетрадь ошибок

`learning.js` расширяет существующий прогресс без сброса данных. План учитывает текущий уровень, ошибки по сроку и последние 20 ответов по теме. Оценка темы использует последний ответ на каждое разное задание в этой выборке. Для статуса «Получается уверенно» нужно от 5 разных заданий, не менее 80% верных без самооценки и отсутствие ошибок на закреплении. Общая точность за всё время остаётся отдельной метрикой.

Подборка до 10 вопросов включает до 3 ошибок по сроку в пределах учебного уровня, до 4 примеров слабых тем и задания текущего уровня. При выборе предпочитаются ещё не решённые вопросы; одинаковые тексты одного формата внутри занятия исключаются. Незавершённая практика продолжается, а не заменяется подборкой.

Ошибка проходит три успешные проверки: первая доступна сразу после разбора, вторая через сутки, третья ещё через 3 дня. Ранние повторы не ускоряют цикл; новая ошибка начинает его заново. Самооценка перевода отменяет ложное несовпадение, сохраняя прежнее расписание, и не подтверждает закрепление. Прежние ошибки переносятся без выдуманных дат и ответов. Расписание и последние ответы входят в JSON и облачный payload аккаунта.

`node check-learning.cjs` проверяет интервалы на управляемых часах, ранние повторы, возврат ошибки, миграцию, перезагрузку, самооценку после продолжения, выбор уровня, новые примеры, недопустимость освоения темы одним вопросом и восстановление копии. В браузере дополнительно проверены мобильный план, ввод с Enter, сохранение занятия и тетрадь ошибок.

## Аккаунты учеников

Публичная версия использует Supabase Auth: регистрация по почте и паролю, подтверждение почты, вход, восстановление и изменение пароля. Прогресс каждого аккаунта сохраняется отдельно от гостя; перенос гостевого прогресса — через JSON вручную. В облако входят результаты диагностики, ошибки, карточки, история, уроки, черновики, XP и аудирование. Изменения сначала сохраняются на устройстве, затем отправляются в аккаунт. При конфликте двух устройств пользователь выбирает версию после скачивания резервной копии. Сброс прогресса в аккаунте также синхронизируется; он не удаляет учётную запись.

Настройка проекта: [docs/accounts-setup.md](docs/accounts-setup.md). Пароли обрабатывает Supabase Auth. Сессия входа и локальная копия прогресса хранятся в браузере; на общем устройстве нужно выходить после занятия. Публичный ключ в `account-config.js` не является секретом. Никогда не добавляйте в репозиторий service_role, secret key или пароль базы.

`node check-account.cjs` проверяет клиент с моделью ответов Supabase: вход, восстановление, изоляцию гостя и пользователей, синхронизацию, конфликты, отсутствие сохранённых паролей и обновление токена. Это не проверка доставки реального письма.

## Вход по телефону

Подготовлен дополнительный вход по коду SMS для российских мобильных номеров. Новый пользователь выбирает «Создать аккаунт»; существующий — «Войти». Электронная почта остаётся доступной. Пароли для SMS-входа не требуются, сессия создаётся только после серверной проверки кода.

Серверный адаптер SMS.ru расположен в `supabase/functions/ekvivalent-send-sms/index.ts`. Он принимает только подписанные Supabase Auth Hooks, ограничивает расходы через закрытый журнал и не сохраняет коды. Реальная отправка заработает после настройки владельцем: [инструкция подключения](docs/phone-setup.md). Пока Phone Provider выключен, сайт показывает, что SMS-вход ещё не подключён, и блокирует отправку.
